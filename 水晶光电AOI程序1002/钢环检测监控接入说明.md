# 钢环检测结果实时监控 —— 接入说明

> 项目：COT 滤光片 AOI（水晶光电）
> 需求：在 Autoframe 程序内新增窗体，显示一个钢环中每颗料的综合检测结果（IR 与 AR 任一 NG 即 NG）；连续出现 30 片 NG 或累计 50 片 NG 时弹出报警。
> 钢环料数：由 CCD1 相机反馈（生产时行×列动态，当前料盘 17 行 × 19 列）；空跑模式固定 3 行 × 4 列且不统计。

---

## 一、实现方案总览

产品数据（ProductData）在 IR 站创建后，沿「IR → 翻转 → 移载 → AR → 机械手」全程是**同一个对象引用**（框架赋值传递）。
因此方案是：在 IR 站接料时把「钢环内料位全局序号」写入 ProductData.RingPos，AR 站完成最终判定（CCD6 ∩ CCD3）后按序号回写全局静态数据源 RingMonitor，监控窗体定时轮询刷新。

```
扩膜站 ──取料(CCD2拍照)──> RingMonitor.TakeOut(料位号)
     │
     └──CCD1识别行列──> RingMonitor.SetRingLayout(行, 列, 空跑)

IR检测1/2 ──摆臂放料完成──> RingMonitor.AssignNextPos(ProductData)  // 写 RingPos

AR检测1/2 ──最终判定──> RingMonitor.OnResult(RingPos, Result, NGReason)

监控窗体 Form_RingMonitor ──Timer 200ms 轮询──> RingMonitor.GetSnapshot()
                          └─ 连续30 / 累计50 NG → 弹窗报警，确认后复位
```

## 四、判定口径与报警逻辑

- **综合结果**：AR 站最终 `Result = CCD6(AR) 结果 ? 原 Result(IR) : false`，即 IR、AR 任一 NG 即 NG。RingMonitor 在 AR 判定后按 RingPos 回写，与产线判定完全一致。
- **连续 30 片 NG**：每颗 NG 时 `连续NG计数 +1`，OK 时清零；达到 30 弹报警，确认后计数清零重计。
- **累计 50 片 NG**：从开始（或上次确认）累计，达到 50 弹报警，确认后清零重计。
- **总统计（总检/OK/NG/良率）**：不清零，可手动「重置统计」。
- **空跑模式**：料盘按 3×4 显示，但**不统计**——总检/OK/NG/良率不计入，也不产生报警（RingMonitor 空跑时跳过取料与结果记录）。
- **生产料盘规格**：17 行 × 19 列（由 CCD1 反馈，窗体料盘网格自动重建为 323 格；蛇形顺序与扩膜站取料一致）；大料盘格子自动用小字号、单行显示 OK/NG，状态变化才重绘避免卡顿。
- **换环**：CCD1 识别新钢环行列时 `SetRingLayout` 更新环号与规格；换环时在途料（上一环尾部）结果仍计入总统计，不显示在当前环格内。

## 六、使用说明

1. 运行 `exe\AutoFrame.exe`（或 VS 中 F5）。
2. 程序主界面「自动」页签下会出现 **「钢环检测监控」** 标签页（由 SystemInit 挂载）。
3. 页面内容：
   - 顶部：当前环号、规格（CCD1 反馈的行×列，空跑显示 3×4）、环开始时间；
   - 中部：**蛇形料盘**（与扩膜站取料顺序一致，自绘控件），灰=待检、黄=已取在途、绿=OK、红=NG；料盘按窗口尺寸自动压缩格子，17×19 等规格默认整盘全部显示（格子最小30×26保证可读，窗口过小时自动出现滚动条兜底）；布局已修复：Fill 容器最后加入，正确扣除顶部/右侧空间，不再被统计区与右侧栏覆盖；
   - KPI：总检测 / OK / NG / 良率；
   - 连续 NG 与累计 NG 进度条（阈值 30 / 50）；
   - 右侧：报警记录列表 + 「确认报警并复位」「重置统计」按钮；下方为「单片结果明细」表格（列：序号/料位/结果/NG原因/时间，最新在前，带垂直滚动条可上下滚动查看每一片）。
4. 报警触发时弹出模态窗口并记录；点「确定」即确认并复位对应滚动计数。

## 七、注意事项

- 若要把改动并入 D 盘原工程：将上述 2 个新增文件拷贝到对应目录，按第三节清单修改 7 个文件（csproj 需手动登记新增 Compile 项），重新编译即可。
- 空跑模式下换环不增加环号显示（无 CCD1 识别），料盘格子数据仍正确。
- 报警目前仅弹窗提示并记录，不联动停机/暂停；如需联动产线动作（如报警停机），可在 `RingMonitor.OnResult` 触发点扩展或由操作员按「确认报警」人工处理。
